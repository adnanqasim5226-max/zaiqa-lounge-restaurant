⚙️ How the Auto-Posting is Set Up (Meta Business Suite / Graph API)

The automatic scheduling is configured using Meta Business Suite Planner (or via Instagram Graph API `/media` container endpoint with `scheduled_publish_time` timestamp in UNIX format for Asia/Karachi timezone).

Method 1: Meta Business Suite (Recommended for Screenshots)
  1. Go to business.facebook.com/latest/planner
  2. Connect your Instagram / Facebook restaurant page.
  3. Click Schedule -> Select the 4 exact Pakistan times:
    • Day 1: 12:30 PM PKT
    • Day 1: 8:00 PM PKT (Reel)
    • Day 2: 1:00 PM PKT
    • Day 3: 7:30 PM PKT
  4. Upload the dish pictures & reel video with the captions shown above.
Method 2: Graph API Cron Script (Node.js / Python)
// Scheduled publishing timestamp (Asia/Karachi)
